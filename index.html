Prácticas de HTML

Una colección de ejemplos para conocer etiquetas HTML, desde la estructura básica hasta elementos semánticos y multimedia.
Las páginas usan HTML sin CSS ni JavaScript.

Ruta de aprendizaje

  1. Estructura y encabezados
  2. Texto y citas
  3. Enlaces, listas e imágenes
  4. Tablas
  5. Formularios
  6. Semántica, interacción y multimedia

Cómo practicar

Abre cada documento en el navegador y revisa el código fuente para relacionar las etiquetas con el contenido que muestran.

En el ejemplo de imágenes y multimedia, cambia las rutas de muestra por archivos que tengas en tu proyecto.
