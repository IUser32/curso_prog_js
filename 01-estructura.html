01. Estructura y encabezados

Un documento HTML comienza con una estructura que indica al navegador cómo interpretar su contenido.

Estructura principal

<!DOCTYPE html> declara que el documento usa HTML moderno.

El elemento <html> contiene la página. El atributo lang indica el idioma del documento.

<head> guarda metadatos y el título de la pestaña; <body> contiene lo que se muestra en la página.

La etiqueta <meta charset="UTF-8"> permite usar correctamente caracteres como ñ y tildes.

Párrafos y saltos

Un párrafo se escribe con <p>. El navegador agrega separación entre párrafos.

Esta frase termina aquí.
La etiqueta <br> inicia otra línea dentro del mismo párrafo.

<hr> representa una separación temática entre contenidos.
