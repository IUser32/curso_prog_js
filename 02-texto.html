02. Texto y citas

HTML ofrece etiquetas para expresar el significado de fragmentos de texto.

Énfasis y resaltado

strong indica importancia; em expresa énfasis.

mark señala un fragmento relevante en este contexto y small suele usarse para anotaciones.

Este dato fue eliminado y este otro fue añadido.

Subíndices, superíndices y abreviaturas

La fórmula del agua es H2O y una potencia puede escribirse como 32.

HTML significa lenguaje de marcado de hipertexto.

Citas

Una cita corta dentro de un párrafo: La práctica hace al maestro.

Una cita extensa se puede separar del texto que la rodea con el elemento blockquote.

El atributo cite puede indicar la fuente de una cita.

Código y contenido preformateado

Para mencionar una etiqueta en línea, se puede usar <header>.

<p>Hola, mundo</p>
<p>Este texto conserva
los saltos de línea.</p>

<pre> conserva espacios y saltos de línea; <code> identifica código.
